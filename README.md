3. Technical Architecture
Language: Pure HTML5 + CSS3 + JavaScript (no frameworks, no build tools)
Styling: Tailwind CSS (via CDN) + custom cosmic gradient
Storage: Browser localStorage (multiple profiles saved forever)
Calculations: Deterministic math functions (reduce-to-single-digit + Master numbers 11/22/33)
Two Systems: Pythagorean (default) + Chaldean (used by Dr. J C Chaudhry agent)
Date Awareness: Uses real browser new Date() so forecasts are always “present timeliness”
Size: Under 30 KB — runs even on low-end phones or feature phones with browser
Zero dependencies on internet, servers, or external APIs.

7. Troubleshooting
Problem
Solution
App looks broken / no styling
Make sure you open the file directly (not through file:// with some browsers blocking Tailwind). Use Chrome/Edge/Firefox.
Date of birth not calculating
Use YYYY-MM-DD format in the date picker.
Profiles not saving
Clear browser cache or allow localStorage (most devices do by default).
“Create Profile” button does nothing
You must fill both Date of Birth and Full Name.
Want to run on phone
Email the index.html file to yourself or upload to Google Drive → open in phone browser.
Want mobile app version
Next phase (Flutter) — we will build it after GitHub upload.
